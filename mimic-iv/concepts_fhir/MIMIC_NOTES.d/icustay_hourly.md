## Chartevents effective-time normalization can alter per-stay HR MIN/MAX
- Affected: `Observation.effectiveDateTime` from `mimiciv_icu.chartevents` and any per-stay `MIN`/`MAX` endpoint derived from it, including `icustay_times.intime_hr` / `outtime_hr`.
- Verified: `icustay_hourly` attempt_0001 embedded Delta probe found 13,913 source/FHIR HR rows for code `220045`; source had two `02:00` groups that FHIR serialized as `03:00` groups with multiplicity two, while demo aggregate endpoints remained exact 140/140. The completed dependency comparison at `mimic-iv/concepts_fhir/concepts/demographics/icustay_times/attempt_0003/comparison.full.json` recorded 8/73,181 endpoint conflicts, demonstrating that `MIN(transform(charttime))` can differ from `transform(MIN(charttime))`.
